# Mission folder search reference

If the UI is given the Cliffs of Dover install folder, it should look in:

"*game root*\missions\Single\"  folder 
as well as the 
"*game root*\parts\bob\mission\campaign\"
"*game root*\parts\bob\mission\Quick\"
"*game root*\parts\bob\missions\Single\"
"*game root*\parts\tobruk\mission\campaign\"
"*game root*\parts\tobruk\mission\Quick\"
"*game root*\parts\tobruk\missions\Single\"

If given the documents folder, it should look in:

"*DocsRoot*\1C SoftClub\il-2 sturmovik cliffs of dover\missions\single\"
"*DocsRoot*\1C SoftClub\il-2 sturmovik cliffs of dover\mission\campaign\"
"*DocsRoot*\1C SoftClub\il-2 sturmovik cliffs of dover\mission\quick\"

Multiplayer paths are documented for later UI work, but are not currently used by the campaign browser:

It can look in the 
"*DocsRoot*\1C SoftClub\il-2 sturmovik cliffs of dover\missions\Multi\"
"*GameRoot*\missions\Multi\" (which contains Co-op and Dogfight folders)
"*GameRoot*\parts\bob\missions\Multi"
"*GameRoot*\parts\tobruk\missions\Multi\" (which contains Co-op and Missions)

Current notes:

- Campaign selector uses campaign paths only, not single mission paths.
- Single mission screen uses single mission paths.
- Quick mission screen uses quick mission paths.
- `missions\Multi` and `parts\*\missions\Multi` are reserved for later multiplayer browser work.
